
# Computer Engineering Portfolio

  

Welcome to my project portfolio. I am a Computer Engineer passionate about building robust systems from the bare metal up to the user interface.

  

This repository serves as a central hub for my technical projects, showcasing my ability to design custom hardware, write efficient embedded firmware, and develop high-level software applications. Whether it is routing high-current motor drivers or integrating cross-language software logic, this repo documents my continuous progression and skill development.

This repository is a WIP and some readme files are still in estonian.
  

---

  

## Repository Structure

  

My work is divided into two primary disciplines.

### Electronics & Hardware

  

This directory contains the schematics, PCB layouts, and embedded C firmware for my custom boards.

  

*  **Focus:** Microcontroller architecture (STM32), power supply design, signal isolation, and real-time hardware interaction.

*  **Featured Projects:**  **HARM** (a high-performance robotics motor control mainboard) and **CoolFridgeGuard** (a low-power smart sensor and audio alarm).

  

### Software & Programming

  

This directory chronicles my software engineering projects from 2023 to the present, demonstrating a steady progression in architectural complexity and code efficiency.

  

*  **Focus:** Algorithms, cross-language integration, low-level memory management, and control systems.

*  **Featured Projects:**  **Pirogov** (Python arcade game), **Tic-Tac-Toe** (C++/Python integration), **Converter** (C memory practice), and a **PID Controller** (C and Raylib).
