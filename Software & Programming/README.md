# Software & Programming Projects

Welcome to the software section of my portfolio. This directory chronicles my programming journey from 2023 to the present, demonstrating a steady progression in complexity, efficiency, and code quality.

As a Computer Engineer, I enjoy working across different levels of the software stack. The projects below showcase my evolution from building high-level Python applications to writing efficient, hardware-adjacent C and C++ code. This portfolio is continuously updated as I tackle new challenges.

---

## Project Directory

### 1. Pirogov (2023)

**Pirogov** is my first large-scale programming project, built from the ground up as a complete arcade game. While my coding standards and architectural approaches have evolved significantly since then, this project served as a critical learning milestone and was recognized for its execution.

* **Language:** Python
* **Core Focus:** Game loop architecture, basic logic, and state management.
* **Achievement:** 1st Place Winner of the course's programming competition.

### 2. Tic-Tac-Toe (T3) (2024)

A classic board game implementation built to explore cross-language integration, balancing raw performance with rapid UI development.

* **Languages:** C++ and Python
* **Core Challenge:** Seamlessly bridging two environments by utilizing C++ for the heavy-lifting game logic and Python for the user interface.
* **Documentation:** Detailed implementation notes are available within the project folder.

### 3. Converter (2025)

A lightweight utility program dedicated to unit conversions. This was strategically built as a stepping stone to master memory management and strict typing before moving into microcontrollers.

* **Language:** C
* **Core Focus:** Mastering C syntax, pointers, and efficient program structuring.
* **Target Application:** Foundational practice in preparation for writing bare-metal firmware for the AT90USB647 development board.

### 4. PID Controller (2026) - *Work in Progress*

An active project focused on translating my previous experience with Python-based control systems into a strictly typed, lower-level environment, complete with real-time graphical visualization.

* **Language:** C
* **Framework:** Raylib
* **Core Challenge:** Implementing accurate proportional-integral-derivative math in C and bridging mathematical outputs with real-time screen rendering.
